Privacy information

Your sleep history stays personal.

Updated 28 October 2026

Purpose and access

Domestic Cyberpunk Sleep is the owner's personal household project. With explicit Google consent, it reads Google Health sleep data to display personal sleep history. The requested permission is googlehealth.sleep.readonly.

Depending on what Google provides, records can include sleep times, stages, durations, summaries, device/source information and record identifiers. This connection does not request Gmail, contacts, location or permission to write Google Health data.

Where information is stored

The authorized connector runs on the private household VM. Its Google permission and separate database credential are stored as encrypted service credentials. It reads the most recent 30 calendar days about once an hour, retaining previously imported records. Connection-setup credentials and validation records are also retained encrypted under the owner's Windows account.

Imported watch records, source versions, owner-written day notes and self-reported sleep windows are stored in the private VM's MariaDB database. Entry timestamps, actual sleep dates and correction history are retained separately. Credentials are kept outside public website files. Household backups may retain copies. These public information pages contain no sleep records or sign-in credentials.

How information is used and shared

Information is used for the owner's personal notebook. It is not sold or used for advertising. Google supplies records when the authorized connector requests them.

The household also uses authenticated ChatGPT tools. If the owner uses the sleep tools to read or annotate the notebook, the requested records, reports, notes and relevant history are shared with ChatGPT for that interaction. The project does not use the API data to train generalized AI models; the owner's separate ChatGPT account settings govern use within that service. The private website does not make household records publicly readable.

Stopping access and removing copies

The owner can revoke the app's Google permission in their Google Account's connected-app settings. Revocation stops future authorized reads; it does not automatically erase previously imported records, notes or backups. Saved local copies can be removed by the owner or household administrator, with backup retention handled separately.

Notes and later imports

Owner-written annotations are separate from imported device records. Imports retain original source versions and preserve annotations and self-reported windows when device records change. Corrections and removals from the ordinary page retain an audit trail. The owner can export the complete sleep notebook and its history from the private site or its authenticated tools.

Public page visitors

The public host is GitHub Pages. These pages contain no analytics scripts, advertising or application cookies. GitHub logs visitors' IP addresses for security purposes, as described in the GitHub Privacy Statement. The public repository contains only these information pages and their hosting settings.

Contact

This project has no public registration. The owner or household administrator can use the developer contact shown in the app's Google consent information for questions about its data practices.
