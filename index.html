A private household notebook

Sleep, with room for context.

Domestic Cyberpunk Sleep is a personal project for viewing the owner's sleep history alongside notes about each day.

This public website explains the project and its data practices. The household notebook and its records are kept separately on a private household system.

What the project does

The project is being built to combine historic sleep exports with read-only access to Google Health sleep records. Day notes are kept separately so a later device-data import can preserve the owner's annotations.

Google Health access

The Google connection requests permission to see sleep data. It does not request permission to edit Google Health records. The owner chooses whether to authorize the connection and can revoke it through their Google Account.

Personal use

This is a private household project. It does not offer public accounts or public access to sleep records.
